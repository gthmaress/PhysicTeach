# Физика — подготовка к коллоквиуму

[Открыть сайт](https://gthmaress.github.io/PhysicTeach/) · [Резервный адрес](https://physics.aglowwhale18.chatgpt.site) · [Репозиторий](https://github.com/gthmaress/PhysicTeach)

Бесплатный сайт без регистрации для телефона и ПК. В курсе 102 карточки формул, 111 определений и формулировок законов, 31 пошаговый вывод. Он охватывает все 23 билета по механике из предоставленных учебных материалов. Запись разобрана полностью; формулировки исправлены и дополнены необходимыми условиями применимости. Самого видео, кадров, таймкодов и ссылок на запись в приложении нет.

- **Темы:** определения и законы, формулы с названием, физическим смыслом, обозначениями и единицами, условиями, объяснением и раскрываемым примером применения; рисунки и пошаговые выводы на одной странице.
- **Тесты:** 71 задача, минимум три на тему; четыре варианта ответа с пояснениями, решение и переход к нужным формулам. Можно повторять только ошибки.
- **Карточки:** 244 вопроса на определения, формулы и выводы из тех же тем. Короткие занятия по 10 или 20 вопросов, повторение ошибок, интервалы 1/3/7 дней.
- **Устный ответ:** таймер и полный связный образец ответа по каждому билету с шестью соответствующими критериями самооценки.

В интерфейсе четыре учебных раздела. Экспорт, импорт, офлайн-копия и увеличенный текст доступны в меню «Сохранение».

## Запуск

Требуется Node.js 20 или новее. Зависимости уже включены в репозиторий.

```sh
npm test
npm run build
npm run dev
```

Предпросмотр — http://127.0.0.1:4173. Сборка проверяет структуру материалов и тестов, все TeX-формулы и отсутствие видеофайлов. Создаются JS с хешем содержимого и `dist/Механика-офлайн.html`, включающий код, шрифты и стили. На телефоне удобнее опубликованный сайт: поддержка локальных HTML зависит от браузера.

## Прогресс

Прогресс хранится только в текущем браузере. Для переноса между устройствами или адресами используйте **Сохранение → Экспорт прогресса**, затем **Импорт прогресса**. Импорт заменяет текущие данные после подтверждения. Экспорт включает статусы тем, интервалы карточек, результаты тестов, черновики и размер текста. Очистка данных браузера удаляет местный прогресс.

Курс полностью переработан, поэтому используется новый идентификатор `mechanics-video` и отдельное хранилище `colloquium.study.video.v1`. Прогресс старого курса `mechanics` не засчитывается автоматически: состав и порядок вопросов изменились. Старое хранилище не удаляется. Резервные копии новой редакции совместимы между её устройствами и адресами.

«Могу объяснить» — ваша самооценка. Правильный тестовый ответ начинает изучение темы, ошибка помечает её для повторения. Сайт не распознаёт речь и не оценивает её автоматически.

## Публикация

Workflow **Build and publish** при обновлении `main` выполняет тесты, сборку и публикует GitHub Pages. В Settings → Pages должен быть выбран GitHub Actions. Для Sites сохраняйте существующий `project_id` из `.openai/hosting.json`.

## Материалы и расширение курса

`dist/content.js` содержит `LESSON_DATA`: исходные данные всех тем. У каждой темы стабильный `id`, `title`, `intro`, `definitions`, `formulas`, `derivations`, `oralAnswer`. Формула содержит `tex`, `title`, `meaning`, `symbols`, `when`, `why`, `example`. Устный ответ — шесть объектов `{criterion, answer, check}` с полными ответами и соответствующими критериями.

`COURSES` собирает темы по группам. `dist/learning.js` строит из тех же данных карточки и связывает образцы ответа; дублировать теорию отдельно не требуется. Новые курсы добавляйте в `COURSES`, используя собственные ID и соответствующее связывание учебных данных. Выбор курса появится автоматически, прогресс разделяется по его ID.

`dist/quizzes.js` хранит задачи: `{id, topicId, question, options, correct, solution, formulaIndices}`. У каждой из четырёх опций есть `id`, `text`, `why`; решение содержит минимум три шага. `formulaIndices` ссылаются на формулы темы, начиная с нуля. Добавляйте новые вопросы в конец и сохраняйте ID; перестановка карточек требует смены редакции или миграции прогресса.

`dist/classroom.js` содержит SVG-схемы. `lesson-ui.js`, `quiz-ui.js` и `app.js` отвечают за представление; `progress-state.js` и `quiz-engine.js` — за сохранение и проверку ответов.

Формулы — TeX без разделителей. Встроенная математика в JS-строках записывается как `\\(...\\)`. Перед публикацией проверьте физический смысл, единицы, ограничения, численные ответы и отображение на телефоне.

При уточнении ключевых пробелов использованы [OpenStax: законы Ньютона](https://openstax.org/books/university-physics-volume-1/pages/5-2-newtons-first-law), [мощность](https://openstax.org/books/university-physics-volume-1/pages/7-4-power), [закон Паскаля](https://openstax.org/books/university-physics-volume-1/pages/14-3-pascals-principle-and-hydraulics) и [NIST SP 811: единицы давления](https://physics.nist.gov/cuu/pdf/sp811.pdf).
