# Физика — подготовка к коллоквиуму

[Открыть сайт](https://gthmaress.github.io/PhysicTeach/) · [Репозиторий](https://github.com/gthmaress/PhysicTeach)

Бесплатное приложение без регистрации: 23 темы по механике, 86 формул с объяснениями, рисунки, выводы и задачи. Работает на телефоне и ПК. Четыре раздела:

- **Темы:** определения, все формулы с обозначениями и условиями, схема, пример с решением, выводы и частые ошибки на одной странице.
- **Тесты:** 69 задач, по три на тему. Четыре варианта ответа, объяснение выбранного варианта, пошаговое решение и переход к нужной формуле. Результаты и черновики сохраняются; можно повторить только ошибки.
- **Карточки:** 188 вопросов для активного повторения. Сначала выбор темы, затем ответ по памяти. Доступны занятия по 10, 20 карточек или без ограничения, интервалы 1/3/7 дней и отдельный повтор ошибок.
- **Устный ответ:** выбор билета, таймер, полный пример правильного рассказа и шесть соответствующих пунктов самооценки.

Боковой панели, плана занятий и вкладок внутри темы нет. Экспорт/импорт, офлайн-копия и увеличенный текст доступны в меню «Сохранение».

## Запуск и проверка

Требуется Node.js 20 или новее. Зависимости для сборки включены в репозиторий.

```sh
npm test
npm run build
npm run dev
```

Предпросмотр: http://127.0.0.1:4173. Сборка проверяет структуру материалов, тестовые задания и все TeX-выражения, создаёт JS с хешем содержимого и файл `dist/Механика-офлайн.html`. Офлайн-файл содержит шрифты, стили и код, его можно открыть на ПК без интернета. Открытие локальных HTML на телефоне зависит от браузера; для телефона удобнее опубликованный сайт.

## Прогресс и перенос

Данные хранятся только в localStorage этого браузера. Облачной синхронизации нет. Меню **Сохранение → Экспорт прогресса** сохраняет JSON; на другом устройстве выберите **Импорт прогресса**. Импорт заменяет местные данные после подтверждения. В файл входят статусы тем, интервалы карточек, результаты тестов, черновики и настройки текста. Очистка браузера удаляет местные данные.

Прогресс привязан к адресу: при переходе с Sites на GitHub Pages или в офлайн-файл перенесите JSON вручную. Резервные копии предыдущих версий совместимы; старые отметки практики, черновики и планы сохраняются в данных, хотя отдельные интерфейсы практики и плана убраны.

Статус «Могу объяснить» — самооценка. Его можно выбрать в теме или после устного ответа. Правильный тестовый ответ начинает изучение темы; ошибка отмечает её для повторения. Три правильных ответа сами по себе не подтверждают умение вывести формулы. Ответы на карточках и устная речь программой не оцениваются.

## Публикация

GitHub Pages публикует сайт при каждом обновлении `main`: workflow **Build and publish** выполняет тесты, сборку и deploy. В Settings → Pages должен быть выбран источник **GitHub Actions**. Серверы, платные API и регистрация посетителей не нужны.

Резервная версия Sites: https://physics.aglowwhale18.chatgpt.site. Настройки Sites лежат в `.openai/hosting.json`. Не создавайте новый проект вместо обновления существующего.

## Добавить следующий коллоквиум

Курс — объект в массиве `COURSES` в `dist/content.js`: `{id, title, subtitle, groups, topics}`. Добавляйте новый курс рядом с текущим. Выбор курса на главной появится автоматически. Прогресс разделён по `course.id`; существующие ID тем и вопросов менять нельзя без миграции.

Тема создаётся фабрикой:

```js
topic('stable-topic-id', 0, 'Заголовок', 'Введение',
  [['Термин', 'Полное определение']],
  [['F=ma', 'Краткое пояснение']],
  [['Название вывода', ['Шаг 1', 'Шаг 2']]],
  ['Типичная ошибка'],
  [['Вопрос', 'Ответ']],
  'Краткий устный ответ')
```

`group` — индекс группы с нуля. Формулы записываются в TeX без разделителей; встроенная математика — `\\(...\\)` внутри JS-строк. Обычный текст экранируется. Добавляйте вопросы в конец: ключи карточек используют индексы `q0…`, дополнительных заданий — `p0…`.

Данные расширения курса:

- `dist/learning.js`: определения, пояснения каждой формулы (`title`, `meaning`, `symbols`, `when`, `why`, `example`), введения к выводам, задачи с решениями, полные устные ответы и критерии.
- `dist/classroom.js`: схема, подпись, связь примера с теорией. При добавлении второго курса связывайте рисунки с уникальными ID тем.
- `dist/quizzes.js`: банк тестов, назначаемый в `course.quizzes`. У каждой задачи стабильные `id`, `topicId`, `question`, четыре `options` с `id`, `text`, `why`, ключ `correct`, не менее трёх шагов `solution` и `formulaIndices` — индексы использованных формул темы. Проверка сборки требует минимум три задачи на тему.

Материалы составляются и проверяются вручную; сайт не генерирует их во время занятий. Для каждого нового курса проверьте физическую корректность, условия применимости и согласованность вариантов ответа с решением.

## Устройство проекта

`lesson-ui.js` отображает единую страницу темы; `quiz-engine.js` проверяет банк и считает баллы; `quiz-ui.js` ведёт попытку теста. `progress-state.js` отвечает за совместимость данных и интервалы карточек. `app.js` содержит навигацию, карточки, устный ответ и перенос прогресса. `warm.css` и `comfort.css` задают округлый Nunito, тёплую палитру и адаптивный интерфейс.

Прямые ссылки: `#topic/m18`, `#topic/m18/derive`, `#topic/m18/formula-2`, `#tests/m18`, `#cards/m18`, `#oral/m18`. Старый маршрут `#topic/m18/check` открывает тест темы; старые `#plan` и `#formulas` ведут к списку тем. Исходные модули объединяются сборкой; сгенерированный `study-*.js` вручную не редактируется.

## Учебные соглашения и приватность

- Классическая механика; ограничения моделей указаны рядом с формулами.
- Затухание: γ = b/(2m), уравнение ẍ + 2γẋ + ω₀²x = f(t). Собственная, затухающая и резонансная частоты различаются.
- qV — расход жидкости, Q — добротность. Для энергии оговаривается отсутствие явной зависимости потенциала от времени.
- Опытные законы не выдаются за математически доказанные; показаны их формулировки и следствия.
- Прогресс, ответы и голос не отправляются на сервер; аналитики нет. В исходниках нет личных данных и учётных записей.

KaTeX 0.16.22 и шрифты поставляются локально. Лицензии MIT и Nunito OFL приложены в `dist/vendor`. Внешних загрузок для отображения формул и шрифтов нет.
