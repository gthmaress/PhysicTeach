# Физика

Статический сайт без сервера приложения, платных API, подписок на библиотеки и базы данных. Исходники сайта лежат в `dist`; команда сборки создаёт готовую веб-версию и автономный HTML. Материал первого курса соответствует 23 вопросам по механике с фотографии пользователя.

## Запуск и сохранение

- Текущая публичная версия: https://physics.aglowwhale18.chatgpt.site — без регистрации.
- Перед локальным запуском: установите Node.js 20+ и выполните `node prepare.mjs`. Установка npm-зависимостей не нужна: библиотеки и шрифты включены в репозиторий.
- Автономно: файл `dist/Механика-офлайн.html`. Все формулы, шрифты, материалы и скрипты включены; интернет не нужен. Откройте в браузере ПК. Способ открытия локальных HTML на телефоне зависит от браузера; для телефона удобнее размещённая версия.
- Локальный предпросмотр: `node server.mjs`, затем http://127.0.0.1:4173.
- Метки тем, интервалы карточек, дата и длина плана хранятся в localStorage браузера. Облачной синхронизации нет. Перенос через пункт «Прогресс» в верхнем меню → «Прогресс и помощь» → экспорт/импорт JSON. Импорт заменяет локальный прогресс после подтверждения.
- Автономный файл и размещённая версия могут иметь разные хранилища. Очистка браузера удаляет локальный прогресс.


## Бесплатный адрес на GitHub Pages

Репозиторий: https://github.com/gthmaress/PhysicTeach. После включения Pages адрес будет https://gthmaress.github.io/PhysicTeach/ — вход посетителям не нужен.

1. Откройте Settings → Pages → Build and deployment → Source и выберите **GitHub Actions**.
2. Откройте Actions → **Build and publish** → **Run workflow** → main → Run workflow.
3. Дождитесь успешного задания deploy. Ссылка появится в окружении github-pages.

Каждое обновление main автоматически проверяет материалы, собирает и публикует сайт. Workflow также можно запустить вручную. Исходники, локальные шрифты и лицензии хранятся в репозитории; сгенерированные JS и автономный HTML создаются при сборке. Никаких серверов и платных API не требуется.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Прогресс привязан к адресу сайта. Перед переходом с Sites на Pages экспортируйте его в «Прогресс и помощь», затем импортируйте на новом адресе.

## Добавить следующий коллоквиум

Данные отделены от интерфейса: `dist/content.js`. `COURSES` — массив курсов. Добавьте новый объект `{id, title, subtitle, groups, topics}`. Выбор коллоквиума в меню появится автоматически; прогресс изолирован ключами `course.id:topic.id`. Существующие ID не менять. Каждый курс может иметь любое число тем и разделов; статистика и план рассчитываются автоматически.

Темы создаются фабрикой:

```js
topic('stable-topic-id', 0, 'Заголовок', 'Введение',
  [['Определение', 'Пояснение']],
  [['F=ma', 'Обозначения, условия и единицы']],
  [['Название вывода', ['Шаг 1', 'Шаг 2']]],
  ['Типичная ошибка'],
  [['Вопрос', 'Краткий ответ']],
  'Каркас полного устного ответа')
```

`group` — индекс в `groups`, начиная с 0. В `formulas` — TeX без разделителей. В обычном тексте можно использовать `\\(...\\)` (с удвоенными обратными слэшами внутри JS-строк). Все остальные фрагменты экранируются как текст. Вопросы автоматически попадают в карточки. Порядок существующих вопросов не менять без миграции ключей карточек: они используют индекс q0, q1 и т.д.; новые вопросы добавлять в конец. Можно добавлять источники в `SOURCES`.

Материалы не генерируются автоматически при использовании приложения. Для нового списка нужно вручную добавить достоверный конспект и проверить формулы. При расширении не заменяйте текущий курс: добавляйте соседний объект.

## Развёрнутый учебный материал

`dist/learning.js` содержит дополнения по ключу курса и темы: понятные определения, пояснения всех формул, введения к выводам, задания с подсказками и решениями, а также готовые правильные устные ответы. `dist/classroom.js` связывает каждую тему с физической схемой, разобранным примером и набором основных формул. Дополнительные формулы раскрываются отдельно. `dist/lesson-ui.js` отображает эти данные. `dist/warm.css` задаёт округлый шрифт Nunito, тёплую палитру и оформление.

Названия формул выделены начертанием Nunito ExtraBold. Все шрифты локальные; лицензии KaTeX MIT и Nunito OFL приложены в vendor.

В практике тема автоматически получает «Могу объяснить», когда все её задания отмечены «Получилось». «Нужно разобрать ещё» переводит её в «Повторить». Сохраняются старые ID тем и карточек q0…; новые задания используют p0… без смещения старого прогресса. Сами ответы ученика не оцениваются программой. Текстовые черновики живут до закрытия страницы; отметки и статусы — в localStorage и экспортируемом файле. В устном ответе сначала доступен полный пример правильного рассказа, затем шесть соответствующих конкретных пунктов самооценки.

Вкладки тем имеют адреса `#topic/m01/theory`, `#topic/m01/derive`, `#topic/m01/check`; они поддерживают возврат назад и прямую ссылку. Приложение собирается в единый JS-файл с хешем содержимого, чтобы пояснения и интерфейс загружались согласованно. Это артефакт сборки, отдельно вручную его не редактировать.

## Проверка и сборка

`node --check dist/app.js` и `node --check dist/content.js` проверяют синтаксис. `node prepare.mjs` проверяет уникальность ID, наличие разделов темы, все TeX-формулы и собирает автономный HTML. Запускайте его перед каждой публикацией после изменений. Автономный HTML — артефакт сборки; исходники находятся рядом в dist.

Внешних загрузок при открытии сайта нет. KaTeX 0.16.22 включён локально, лицензия MIT в `dist/vendor/LICENSE`. Для обновления нужен только повторный выпуск статических файлов; ежемесячных расходов на вычисления нет. Условия доступа к размещённой версии определяются платформой Sites; автономная копия от хостинга не зависит.

## Учебные соглашения

- Классическая механика, инерциальные системы отсчёта.
- Гамма затухания: γ = b/(2m); уравнение ẍ + 2γẋ + ω₀²x = f(t).
- qV — расход жидкости, Q — добротность.
- ω₀, ωd и Ωres различаются; приближения отмечены.
- Статусы тем — самооценка. Ответы на карточках не оцениваются автоматически.
- Опытные законы не выдаются за математически выведенные; представлены их формулировки и следствия.

## Приватность

Приложение не отправляет прогресс, ответы и голос на сервер и не использует аналитику. Доступ к размещённому сайту контролируется платформой. Текущая размещённая версия публичная и не требует входа. В исходниках нет пользовательского прогресса или учётных данных.
